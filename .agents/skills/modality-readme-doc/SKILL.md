# README 与文档规范

README 是本仓库唯一的人类权威文档（约 600 行）；改代码影响其描述时必须同 PR 更新，纯重构通常不需要。

## 结构约定

- 章节顺序：功能特点 → 模块清单 → 快速开始 → 部署指南 → 使用示例 → 配置速查 → 贡献指南 → 许可证；新内容并入既有章节，不随意新开
- 目录（TOC）与章节同步维护
- 表格优先承载对照信息（模块、配置、常见问题）；步骤用编号列表；命令用 ```bash 代码块
- 配置速查指向各库 `*Properties` 类，不复制全量键值

## 文案

- 全中文（同代码规范）；算法名、MIME、协议头、字符集保留原文
- 术语沿用既有译法：租户、账号体系、会话、令牌、数据范围
- 命令、类名、配置键必须与代码一致（改完用 rg 抽查）
- 相对链接有效，指向仓库内文件用相对路径

## 精简原则（参考 readme-trim 提交）

- 一个事实只有一个家：功能在 README、执行细节在配置 / 脚本、决策依据在 notes；不三处重复
- 一句能说清的不写一段；重复示例直接删；与 AGENTS.md 重叠的规则 README 保留人类可读版
- 有疑问以「删掉后读者会不会找不到这件事」为准，不会就删

## 检查清单

- [ ] TOC 无死链；新增 / 删除章节已登记
- [ ] 命令、类名、配置键与代码一致（rg 验证）
- [ ] 无英文残留（约定保留项除外）；无空话与 AI 腔
- [ ] 与 AGENTS.md、notes 无内容冲突
