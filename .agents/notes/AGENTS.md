# AGENTS.md — Agent Notes

本目录是决策记录树，规则全文见 [README.md](README.md)。写 / 改笔记时：

- 每条新笔记触发一次 supersession 检查：搜同主题旧笔记，完全取代且已实施的**在同一次改动里**归档，部分取代的保持活跃并交叉链接
- 新笔记从 `../templates/note-*.md` 骨架起步；归档 / 取代的完整操作见 `../skills/modality-archive-agent-notes/SKILL.md`
- `archived/` 下一切是冻结快照：不编辑、不翻译、不重排，也不作为现状依据
- 笔记与代码事实保持同步：后续改动改了路径、命名、默认值，同期更新对应 `implemented/` 笔记中的事实描述
